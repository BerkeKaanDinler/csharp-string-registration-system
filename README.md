# C# String Registration System

A console-based user registration and string processing application built with C# and .NET.

This project was developed as part of my C# learning journey to practice string manipulation, control flow, loops, and text processing.

## Features

- User registration with name, surname, and email
- Input validation using `IsNullOrWhiteSpace`
- Text normalization using `Trim`
- Uppercase and lowercase conversions
- Character analysis using `Length` and `foreach`
- String comparison using `StringComparison`
- Gmail domain detection
- Random 8-character uppercase user code generation
- Formatted registration reports using `StringBuilder`
- Registration date and time display

## Technologies

- C#
- .NET
- Console Application

## How to Run

Make sure the .NET SDK is installed.

```bash
dotnet restore
dotnet run
```

## Notes

This project is for educational purposes.

The generated user code is not intended for security-sensitive authentication or OTP use.

The application does not store user information in a database.
